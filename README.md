# EEG-Based Cognitive Decline Detection Using Recurrence Plot Representation and Hierarchical Deep Learning (ResNet)

B.Tech (Computer Science and Engineering) final-year major project.

> **Academic research prototype. This is not a clinically validated diagnostic system** and must not be used to diagnose Alzheimer's disease, frontotemporal dementia or any other condition.

## 1. Overview
Resting-state EEG is converted into recurrence-plot images and classified by a two-stage hierarchical pipeline built on a modified ResNet18:

```
EEG (.set) → band-pass + notch → 2 s epochs → 3-channel recurrence plot (64×64)
   Stage 1: Healthy Control  vs  Cognitive Decline
      └─ if Decline → Stage 2: Alzheimer's Disease (AD)  vs  Frontotemporal Dementia (FTD)
```

## 2. Problem statement
Dementia subtypes can be hard to separate clinically. EEG is inexpensive and non-invasive, so this project explores whether deep learning on EEG-derived images can (1) separate healthy individuals from individuals with cognitive decline and (2) distinguish Alzheimer's disease from frontotemporal dementia.

## 3. Research objectives
1. Convert multichannel EEG epochs into image representations suitable for CNNs.
2. Apply a transfer-learned ResNet18 to the two binary tasks.
3. Evaluate with subject-wise data splitting to reduce the risk of leakage between epochs of the same person.

An earlier approach (graph representations of 19-channel EEG, about 35,254 graphs, classified with GNN/GAT models) did not give sufficiently reliable performance and was replaced by the recurrence-plot approach in this repository. The graph code is not included.

## 5. EEG preprocessing (`preprocessing.py`)
- Load EEGLAB `.set` files with MNE; FIR band-pass 0.5–45 Hz (Hamming window) and 50 Hz notch filter.
- Segment each recording into 2-second epochs with 1-second overlap.

## 6. Recurrence-plot generation (`preprocessing.py`)
For each epoch, each channel and each band (theta 4–8 Hz, alpha 8–13 Hz, beta 13–30 Hz): FFT band-pass → 64 samples → pairwise distance matrix normalised by its maximum → combination of a soft similarity map and a thresholded map (threshold 0.2). The per-channel plots are averaged within each band, giving a 3 × 64 × 64 image per epoch. A single-channel PSD-spectrogram representation is also implemented (`--representation psd`).

## 7. Modified ResNet18 (`model.py`)
ResNet18 with ImageNet weights, with the first convolution replaced by a 3×3 stride-1 convolution and the max-pool removed (for small 64×64 inputs). The classification head is Dropout → Linear(512, 256) → ReLU → Dropout → Linear(256, 2). A lightweight CNN alternative (`--architecture eegnet`) is also included.

## 8. Hierarchical classification
- **Stage 1:** Healthy Control (0) vs Cognitive Decline (1).
- **Stage 2:** Alzheimer's Disease (0) vs Frontotemporal Dementia (1), trained only on AD and FTD subjects (optionally warm-started from the Stage 1 checkpoint).

Inference (`predict.py`, `app.py`) runs Stage 1 first and runs Stage 2 only if Stage 1 predicts Cognitive Decline.

## 9. Training methodology (`train_stage1.py`, `train_stage2.py`)
AdamW (backbone learning rate = 0.1 × head learning rate), cosine-annealing schedule, gradient clipping, label smoothing 0.1, dropout 0.5, class-balanced sampling on the stage label, epoch augmentation (noise + time shift), early stopping and best-checkpoint selection on validation macro-F1. Defaults: 40 epochs, batch size 32, learning rate 1e-3 (Stage 1) / 5e-4 (Stage 2), seed 42.

## 10. Evaluation methodology
Subjects are divided into training / validation / test sets (default 70 / 15 / 15, seed 42) before epochs are assigned, so all epochs of a subject remain in one partition. Accuracy and macro-F1 are reported on the held-out test subjects, with a per-class report, computed over individual EEG epochs.

## 11. Results
*Source: approximate ranges reported by the author from the project's experiments and review presentations. Training logs and test reports are not part of this repository, so the figures have not been independently re-checked here, and they are ranges, not the output of a single documented run.*

| Metric | Stage 1: Healthy vs Cognitive Decline | Stage 2: AD vs FTD |
|---|---|---|
| Accuracy | ≈ 59–62 % | ≈ 70–73 % |
| Macro F1 | ≈ 0.59–0.61 | ≈ 0.45–0.48 |

Stage 1 was relatively consistent. Stage 2 accuracy is higher but its macro-F1 is weaker, indicating that AD and FTD were not classified in a balanced way. These results are modest and do not indicate clinical-grade performance.

## 14. How to run
Dataset layout expected by the code:

```
dataset_root/
  participants.tsv        # columns: participant_id, Group (C / A / F)
  sub-001/eeg/*.set
  sub-002/eeg/*.set
  ...
```

```bash
# 1. Precompute and cache recurrence-plot images (once)
python dataset.py --data_root /path/to/dataset --cache_dir /path/to/eeg_cache

# 2. Train Stage 1, then Stage 2
python train_stage1.py --data_root /path/to/dataset --cache_dir /path/to/eeg_cache --output_dir runs/stage1
python train_stage2.py --data_root /path/to/dataset --cache_dir /path/to/eeg_cache --output_dir runs/stage2 \
       --stage1_ckpt runs/stage1/stage1_best.pt

# 3. Inference on one cached image array or one raw .set file
python predict.py --input_npy sample.npy
python predict.py --input_set subject.set
```

Quick CPU runs: add `--max_subjects 10 --max_epochs_per_subject 400`. Use the same seed and subject limits for both stages. Checkpoints are not distributed; `predict.py` and `app.py` expect `runs/stage1/stage1_best.pt` and `runs/stage2/stage2_best.pt`. Both classify a single 2-second epoch (the middle one) of the input.

**Example images:** edit the `file_path` at the top of `imgs.py` to point to one of your cached `*_imgs.npy` files, then run `python imgs.py`; it writes `sample_1.png` … `sample_3.png` into the current folder.

## 15. Streamlit application
```bash
streamlit run app.py
```
Run it from the repository root after both checkpoints exist. Upload a pre-computed `.npy` image array or a raw `.set` file and click **Run Inference**; the app shows the Stage 1 and Stage 2 probabilities. It is a demonstration of the research prototype, not a diagnostic tool.

## 17. Limitations
- Academic prototype; not clinically validated; not for diagnosis.
- Small number of subjects, so the held-out test set contains few people and results can vary with the split.
- Metrics are computed per EEG epoch; no external validation dataset; the split is not stratified by class.
- Modest performance, especially macro-F1 for AD vs FTD.
- Reported figures are approximate ranges without accompanying logs (Section 11).
